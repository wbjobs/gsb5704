# 图片拼接工坊

纯前端多图拼接工具：长图 / 九宫格 / 四宫格 / 自由布局。无构建、零依赖。

## 运行

推荐用本地静态服务器（Worker 在个别浏览器上对 `file://` 有限制）：

```bash
python3 -m http.server 8080
# 打开 http://localhost:8080
```

直接双击 `index.html` 在 Chrome/Edge 下也可运行（Worker 通过 Blob URL 创建）。

## 功能

- **四种布局**：竖向长图、九宫格（3×3）、四宫格（2×2）、自由布局
- **可调参数**：间距、外边距、背景色/透明背景、圆角、边框粗细与颜色、cover/contain
- **布局专属参数**：长图宽度、宫格单格尺寸（自动/手动）、自由画布宽高
- **素材管理**：添加、删除、替换、清空；底部缩略图条用指针拖拽排序
- **自由布局**：预览区直接拖动图片、右下角手柄缩放，越界自动钳回；缩略图排序同步
- **导出**：PNG（保留透明）/ JPEG / WebP（不支持时自动隐藏），可调质量，可取消，带进度
- **大尺寸保护**：实时预估导出像素；>40MP 弹确认，单边 >16384px 或 >104MP 直接拦截

## 边界与性能

| 场景 | 处理方式 |
| --- | --- |
| 尺寸不一致 | 长图统一宽度按比例缩高；宫格统一格子 + cover/contain；自由布局按各自比例 |
| 超大图片（如 50MB） | 只读文件头（前 1MB，JPEG/PNG/GIF/WebP 均可解析尺寸），不解码整图；缩略图缩到 ≤600px；导出按每个格子所需分辨率解码（上限 8192px） |
| 透明通道 | 缩略图用 PNG；`getImageData` 采样检测 alpha；导出 PNG + 透明背景时完全不填充（JPEG 自动填背景并提示） |
| 导出尺寸过大 | 40MP 警告 / 16384px、104MP 硬拦截；OffscreenCanvas 分配失败也会报错 |
| 布局越界 | 自由布局坐标被夹回内容区，超宽项自动缩回 |
| 主线程不卡 | 全部解码/绘制/编码在 Web Worker + OffscreenCanvas 内完成；主线程只做 DOM 预览（rAF 合帧） |
| EXIF 方向 | `createImageBitmap({ imageOrientation: 'from-image' })`，不支持的浏览器走兜底 |

## 文件结构

- `index.html` — 界面结构
- `style.css` — 样式
- `js/engine.js` — 纯逻辑（布局计算/尺寸检查/图片头解析/解码与 Worker 主逻辑），无 DOM 依赖
- `js/app.js` — 主线程：状态、DOM 预览、指针拖拽排序、自由布局交互、导出流程
