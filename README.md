# 图片拼接工作台

零依赖的本地图片拼接工具，所有图片均通过 File API 与 Web Worker 在浏览器本机处理，不上传服务器。

## 运行

Worker 与 ES Module 需要通过 HTTP 服务打开：

```bash
python3 -m http.server 8000
```

然后访问 `http://localhost:8000/`。

## 功能

- 支持一次选择或拖入多张图片。
- 支持长图、四宫格、九宫格和自由布局。
- 长图保持各图宽高比并统一导出宽度；宫格使用正方形容器，图片按 `contain` 等比缩放，不裁剪内容。
- 自由布局支持 Pointer Events 拖拽移动和右下角缩放，位置自动限制在画布内。
- 缩略图列表支持拖拽排序、删除和原位替换。
- 可调间距、背景色、背景不透明度、圆角、边框宽度和边框颜色。
- 支持 PNG、WebP、JPEG 导出；PNG/WebP 保留透明通道，JPEG 自动用背景色填充透明区域。
- 解码、缩略图、绘制和编码均在 Web Worker 中执行；主线程仅负责 DOM 与轻量布局计算。
- Worker 会解析常见图片头并优先让浏览器原生降采样，导出源图长边限制为 4096px，降低超大图导致的内存压力。
- 导出尺寸超过 8000px 或 64,000,000px² 时提示风险；超过 16384px 或 100,000,000px² 时阻止导出，并提供“自动缩小到安全尺寸”。

## 文件

- `index.html`：页面结构与控制面板。
- `styles.css`：界面、透明棋盘格、拖拽和响应式样式。
- `src/layout.js`：预览和导出共用的纯布局算法与尺寸限制。
- `src/worker.js`：图片头解析、受控解码、缩略图、圆角/边框绘制和 Blob 编码。
- `src/app.js`：DOM、状态、Pointer Events、File API 和 Worker 通信。
